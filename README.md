# Jordan Stephens Portfolio

A personal portfolio website showcasing Jordan Stephens's projects, technical interests, and
creative work — a static, dependency-free site built with a Swiss/industrial visual system.

## Live Site

**[jstephens-create.github.io/Portfolio](https://jstephens-create.github.io/Portfolio/)**

## Current Pages

| Page | Description |
|---|---|
| [Home](index.html) | Hero, About, Selected Work, Contact |
| [TouchDesigner](touchdesigner.html) | Real-time visual studies and video work |
| [Photography](photography.html) | Street and Architecture photo collections with a keyboard-accessible viewer |
| [Project Title](project-title.html) | Reserved for a software development case study |
| [Aliases](Aliases.html) | Creative identity record (HOWYKJORDAN) |

Every page shares the same sidebar navigation, which collapses into a toggled menu below 700px
width.

## In Development

Five additional sections — Leadership, Business, Technology, Career Planning, and Wellness —
are being built to document growth during the i.c.stars program. **These pages are not part of
the live site yet.** They're developed on a separate branch and are only merged once a section
has real, reviewed content; no page is published with placeholder text.

## Technologies Used

- HTML5
- CSS3 (custom properties, CSS Grid/subgrid, responsive design)
- Vanilla JavaScript (no frameworks, no build step)
- Git / GitHub Pages

## Deployment

Served directly from the `main` branch root by GitHub Pages, with no build step. Changes are
only merged to `main` after a manual check for responsiveness, keyboard accessibility, working
links, and — for any new content — that it's complete and approved rather than placeholder text.
